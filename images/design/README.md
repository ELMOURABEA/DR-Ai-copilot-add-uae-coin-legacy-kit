## Adding Images

To add these images to the repository:

1. Download each image from the source URLs listed above
2. Save them in this directory (`images/design/`) with the specified filenames
3. Ensure images are in high resolution (preferably PNG format for best quality)
4. Commit and push the changes

## Image Specifications

- **Format:** JPG or PNG (PNG preferred for quality)
- **Resolution:** High resolution suitable for presentations and printing
- **Color Space:** RGB
